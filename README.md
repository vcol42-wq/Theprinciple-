# The Principal Web - نسخة الويب الشاملة 🌐

نسخة الويب الشاملة والمطابقة 1:1 لتطبيق أندرويد من **نظام الإدارة المدرسية الموحد (The Principal)**، تم تصميمها لتعمل كـ **Progressive Web App (PWA)** على أي نظام وأي جهاز في العالم:
* 🍏 **آيفون وآيباد (iOS / iPadOS)**
* 🤖 **هواتف وأجهزة أندرويد (Android)**
* 💻 **أجهزة الكمبيوتر والماك واللينكس (Windows / Mac / Linux / Chromebook)**

---

## 🌟 الميزات والمطابقة التامة مع تطبيق الأندرويد:
1. **نفس التصميم وتجربة المستخدم (Material 3 Mobile-First):**
   * شاشة البداية المتحركة (Splash).
   * بوابات الدخول الثلاث: **المعلم 👨‍🏫**، **الطالب وولي الأمر 🎓**، **المدير والمشرف 👑**.
   * الربط السحابي التلقائي عبر كود المدرسة أو مسح باركود الـ QR عبر كاميرا الجهاز.
2. **سجل الدرجات المعتمد وزارياً (Grade Register):**
   * درجات الشهر الأول، الشهر الثاني، نصف السنة، الفصل الثاني، والسعي السنوي والنهائي.
   * حساب تلقائي مباشر للمعدلات ومراعاة المواد الخاصة (التربية الفنية والرياضية والأخلاقية).
3. **المزامنة السحابية المباشرة (Supabase):**
   * متصلة بنفس قاعدة بيانات Supabase المشتركة مع تطبيق سطح المكتب والأندرويد.
   * أي تعديل يتم هنا يظهر فوراً في تطبيق الأندرويد وسطح المكتب.
4. **جدول الحصص الأسبوعي وسجل الغيابات والجرس المدرسي الذكي.**

---

## 🚀 كيفية التشغيل المباشر:
1. افتح المجلد: `e:\boss\SchoolSystem_Web`
2. اضغط مرتين على ملف: **`تشغيل_نسخة_الويب.bat`**
3. سيظهر لك رابط محلي ورابط شبكة (مثل: `http://192.168.1.X:5173`) يمكنك فتحه من متصفح أي هاتف آيفون أو أندرويد متصل بنفس شبكة الواي فاي!

---

## 📲 كيفية التثبيت كتطبيق على الهواتف (PWA):
* **على هواتف آيفون (Safari):**
  اضغط على زر المشاركة (Share) ثم اختر **"إضافة إلى الصفحة الرئيسية" (Add to Home Screen)**.
* **على هواتف أندرويد (Chrome):**
  اضغط على خيارات المتصفح (⋮) ثم اختر **"تثبيت التطبيق" (Install App)**.

سيعمل التطبيق بملء الشاشة وبشكل مستقل بدون شريط المتصفح وبسرعة فائقة.

---

## ☁️ خطوات النشر على الإنترنت مجاناً (لجميع المدارس):
1. شغّل ملف: **`بناء_نسخة_الويب_للنشر.bat`** لإنشاء مجلد `dist`.
2. يمكنك سحب وإفلات مجلد `dist` إلى موقع **[Netlify Drop](https://app.netlify.com/drop)** أو نشره على **Vercel** أو **Cloudflare Pages** ليصبح لديك رابط إنترنت عالمي مجاني (مثل: `https://my-school.netlify.app`) يمكن لأي معلم أو طالب في العراق فتحه واستخدامه فوراً!
